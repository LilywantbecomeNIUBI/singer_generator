# AD9959 M1 参考例程对照审计

对照基准：`AD9959模块资料-V2.4/DDS开发板-点频9959(ok)-V2.4/HARDWARE/AD9959/AD9959.C`。

## 当前 M1 与参考例程一致的部分

| 项目 | 参考例程 | 当前 M1 |
|---|---|---|
| 串行实现 | GPIO模拟时序 | GPIO模拟时序 |
| GPIO速度 | 2 MHz | `GPIO_SPEED_FREQ_LOW`（2 MHz） |
| 空闲时钟 | SCLK低 | SCLK低 |
| 位序 | MSB first | MSB first |
| 串行模式 | 默认单比特两线写模式 | 默认单比特两线写模式 |
| 写事务 | CS低后发送地址和数据 | 相同 |
| 更新位置 | CS仍为低时产生IO_UPDATE | 相同 |
| 复位 | 低-高-低 | 低-高-低，使用更保守的1 ms保持时间 |
| FR1 | `D0 00 00` | `D0 00 00` |
| FR2 | `20 00` | `20 00` |
| CH0选择 | `10` | `10` |
| 1 MHz CFTW0 | 截断计算 | `00 83 12 6E`，同样截断 |
| 0相位 CPOW0 | `00 00` | `00 00` |
| 满幅 ACR | `00 13 FF` | `00 13 FF` |
| CSR更新 | 每次选择通道后更新 | 相同 |
| 目标寄存器更新 | 每次写入后更新 | 相同 |

参考例程中的CFR、LSRR、RDW和FDW写入均被注释，当前M1也不写这些寄存器。

## 有意保留的范围差异

参考例程启动时依次配置四个通道；M1只配置物理CH0，因为本阶段目标仅为逻辑CH1的1 MHz点频输出。这不会改变CH0寄存器的写入内容或时序。

## 必须满足的硬件固定电平

参考例程在通信前主动设置：

- `P0=P1=P2=P3=0`；
- `SDIO1=SDIO2=SDIO3=0`；
- `PWR_DWN=0`、`RESET=0`、`IO_UPDATE=0`、`SCLK=0`、`CS=1`。

当前软件已利用现有接线把PB4连接的SDIO2配置为2 MHz推挽输出低。SDIO1、SDIO3和P0-P3没有分配MCU控制脚，必须由硬件可靠下拉到GND，不能悬空。SDIO3在默认单比特模式下承担SYNC_I/O输入，浮高可能中止串行通信。

## 验证边界

该基线刻意移除了三线读回功能，避免为诊断而改变已验证例程的串行模式。编译通过只能确认移植代码和工程接口一致；是否真正到达DDS仍需用示波器或逻辑分析仪检查模块排针端的CS、SCLK、SDIO0和IO_UPDATE。
